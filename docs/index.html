Как это работает

Парсер собирает VLESS-конфиги из десятков публичных GitHub-коллекторов, оставляет только VLESS + XHTTP, резолвит каждый хост в IP и сверяет с CIDR-диапазонами российских провайдеров (данные из RIPEstat). Затем измеряет латентность и ранжирует серверы — лучшие первыми.

Имена ключей в формате 🇷🇺:YA #01 · 35ms — флаг страны, провайдер, ранг и скорость. Открытый исходный код: GitHub.
